# Tweezy 프로젝트 핵심 원칙

## 브랜드
- 서비스명: Tweezy (한글: 트위지)
- 컨셉: "핀셋으로 정확히 집어낸다" — 수많은 종목 중 원하는 조건에 맞는 것만 정확히 찾아냄
- 도메인: tweezy.app (메인), tweezy.kr (보조/리다이렉트)

## 제품 철학
1. 핵심 설계 원칙: "쉽지만 강력한 필터"
   - 계산 로직이 단순할 것
   - 검증된 투자 원칙(대가들의 원칙, 실전 검증된 패턴)에 기반할 것
   - 초보자가 결과를 보고 왜 나왔는지 바로 이해할 수 있을 것
2. 토스 스타일 브랜딩 원칙: "이 문구를 투자 지식이 전혀 없는 친구에게 보여줬을 때, 3초 안에 이해되는가?"
   - 모든 필터명, UI 카피, 화면 문구는 이 기준을 통과해야 함
   - 어려운 지표를 쉬운 문장으로 "번역"하는 것 자체가 핵심 가치
3. 목적은 순수한 필터링/검색/스크리닝 — 투자자문이 아님

## 이지모드 / 프로모드 구조
- 이지모드: 자연어 요약 카피 + 원클릭 프리셋 (초보자 대상)
- 프로모드: 수치 직접 조정, 자유로운 AND/OR 조합 (숙련자 대상)
- 내부적으로는 동일한 필터 엔진 사용, UI 레이어만 분리
- 이지모드 결과 화면에는 "더 알아보기" 버튼으로 프로모드(실제 수치/공시 원문)로 연결

## 법적 리스크 회피 원칙 (유사투자자문업)
- "사라/팔라" 등 매수·매도 표현을 절대 사용하지 않음
- 백테스트 결과는 공개하지 않음
- 커뮤니티 기능에서도 수익 인증/성공사례만 골라 노출하는 방식 금지 — 활용법 공유 중심으로 제한
- 모든 사용자에게 동일한 조건이 동일하게 적용되어야 함 (개인화된 종목 추천 금지)
- 앱 초기 실행 시 및 필터 결과 화면에 "투자자문 아님, 정보제공 도구" 면책조항 상시 노출

## 필터 카테고리

### 1. 투자 대가 프리셋 (6인)
각 인물 소개(누구인지/성과/원칙 설명 버튼 포함)

**워렌 버핏 (가치투자/우량주)**
- ROE 최근 3개년 평균 15% 이상, 각 연도 10% 이상
- 부채비율 100% 이하
- 영업이익률 최근 5개년 표준편차가 평균의 20% 이내, 평균 10% 이상
- 최근 5개년 연간 순이익 전부 흑자
- PBR 3배 이하

**피터 린치 (성장주/GARP)**
- PEG 1.0 미만
- 최근 분기 전년동기대비 순이익 증가율 15% 이상 (최근 4분기 중 3개 이상 충족)
- 최근 분기 전년동기대비 매출 증가율 10% 이상
- 부채비율 100% 이하
- 유통주식 대비 기관 보유 비율 30% 이하

**윌리엄 오닐 (CANSLIM/모멘텀)**
- 분기 순이익 증가율(C): 전년동기대비 25% 이상
- 연간 순이익 증가율(A): 최근 3개년 연평균 25% 이상, 3개년 모두 전년대비 증가
- 신고가(N): 현재가 52주 신고가 대비 -15%~0%
- 유통주식 수(S): 1억 주 이하 (시장별 조정 필요)
- RS Rating(L): 상위 20% 이내 (Rating≥80)
- 기관 매수(I): 최근 4주 기관 순매수 누적 플러스
- 시장 방향성(M): KOSPI/KOSDAQ 지수가 60일 이동평균선 위 (시장 전체 필터, 종목과 별도 적용)

**벤저민 그레이엄 (딥밸류)**
- PBR 1.0 미만
- PER 10 이하
- 유동비율 2.0 이상
- 장기부채가 순유동자산(유동자산-유동부채)의 100% 이하
- 시가총액 ≤ (유동자산-총부채) × 0.67 (NCAV 기준)
- 최근 5개년 연속 배당 지급

**마크 미너비니 (VCP/추세템플릿)**
- 현재가 > 150일선 및 200일선
- 150일선 > 200일선
- 200일선 최소 1개월간 상승 추세
- 현재가 > 50일선, 50일선 > 150일선 > 200일선
- 현재가가 52주 최저가 대비 +30% 이상
- 현재가가 52주 최고가 대비 -25% 이내
- RS Rating 70 이상
- 최근 10일 평균거래량이 최근 50일 평균거래량 대비 70% 이하 (거래량 마름)

**조엘 그린블라트 (마법공식)**
- 이익수익률 = EBIT ÷ (시가총액+총부채-현금성자산)
- 투하자본이익률(ROC) = EBIT ÷ (순운전자본+순고정자산)
- 두 지표 각각 순위 매겨 합산, 합산 순위 상위 20~30개 종목
- 시가총액 1,000억원 이상 (초소형주 제외)

### 2. 기술적 패턴 (VCP 계열, 미너비니 필터와 로직 공유)
- 기간별 하락률 + 펀더멘털 기본조건 병행
- 전고점 돌파 임박 / 전고점 돌파 완료
- 거래량 마름
- 박스권

### 3. 수급 필터 (한국 시장 특화, 전일 기준 데이터)
- 기관 순매수 (기간 선택 가능)
- 외인 순매수 (기간 선택 가능)
- 연기금 순매수 (기관과 별도 항목)
- 기관+외인 쌍끌이 매수
- 연기금+외인 쌍끌이 매수
- 기관+외인+연기금 트리플 매수
- 연속 순매수 여부는 사용자가 직접 판단 (자동 연속성 계산 로직은 없음)

### 4. 펀더멘털 모멘텀
- 흑자전환 (전년 동기 대비 기준 권장)
- 순이익 지속상승 (분기/연간, 연속 기간 선택 가능)
- 매출 지속상승 (분기/연간, 연속 기간 선택 가능)

### 5. 차별화 필터 (경쟁사에 없는 한국 시장 특화)
- 자사주 매입/소각
- 임원·최대주주 지분 매입 (내부자 매수)
- 지수 편입 임박 (코스피200, MSCI 등)
- 공매도 잔고 필터:
  - 잔고 수준: 유통주식 대비 5%(관심)/10%(높음)/15%(매우 높음, 숏스퀴즈 후보)
  - 변화 추세: 기간 선택(1주/2주/1개월/3개월) + 증감률(±20% 이상)
  - 급감/급증/둘다 토글
  - 실제 임계값은 KRX 전체 종목 분포 확인 후 상대적 기준(상위 X%)으로 조정 권장
- 실적 컨센서스 상향조정

### 6. 자연어 이지모드 프리미엄 필터 (호기심 유도형, 유료 전환 포인트)
- "사장님이 자기 돈으로 산 종목" = 내부자 매수
- "회사가 자기 주식을 사들이고 있어요" = 자사주 매입/소각
- "국민연금이 담은 종목" = 연기금 순매수
- "외국인과 기관이 동시에 사고 있어요" = 쌍끌이 매수
- "셋 다 한꺼번에 사들이는 중" = 트리플 매수
- "공매도 세력이 발 빼는 중" = 공매도 잔고 급감
- "적자였다가 흑자로 돌아선 회사" = 흑자전환
- "N분기 연속 이익이 늘고 있어요" = 순이익 지속상승
- "신고가를 코앞에 뒀어요" = 전고점 돌파 임박
- "조용히 매집 중인 것 같은 종목" = 거래량 마름 + 박스권
- "애널리스트들이 눈높이를 올리고 있어요" = 컨센서스 상향
- "지수에 곧 편입될 수도 있는 종목" = 지수 편입 임박
- "바닥 찍고 반등 조짐" = 낙폭과대 + 펀더멘털 기본조건

무료: 결과 개수만 노출("N개 종목이 조건에 맞아요 🔒") → 유료 구독 시 전체 리스트 공개

## 시가총액 규모 기준 (한국 시장)
- KRX 공식 분류는 순위 기준(코스피 1~100위 대형/101~300위 중형, 코스 드 101~400위 중형)이라 시황에 따라 유동적
- 근사 금액 기준(참고용, 시장 상황에 따라 조정 필요): 대형주 2조원 이상 / 중형주 3,000억~2조원 / 소형주 3,000억원 미만
- 초소형주 제외 필터(오닐, 그린블라트 등)에는 3,000억원을 최소 커트라인으로 잠정 적용

## 개발 단계 원칙
- MVP 범위: 1단계는 한국 시장 + 앱스토어/구글플레이만 (토스 미니앱, 미국 시장은 이후 확장)
- 백테스트는 각 필터 기준값 검증용으로 내부적으로 수행하되, 결과는 사용자에게 공개하지 않음
- API 키/계정정보는 .env 파일로 분리, .gitignore 등록 필수, GitHub Secrets와는 별도로 로컬에도 설정 필요

## 브랜드 철학 — "번역"이 곧 제품이다

### 핵심 통찰
토스가 성공한 핵심은 어려운 개념을 쉬운 말로 "번역"하는 것 자체를 상품으로 만든 것.
계좌이체, 신용점수, 보험 같은 딱딱한 금융 상품을 누구나 이해하는 문장으로 풀어서
진입장벽을 없앤 것이 토스의 본질. Tweezy는 이 공식을 주식 스크리너에 적용한다.

### 이 철학이 Tweezy에 적용되는 방식

1. **"기능"이 아니라 "번역"을 파는 것**
   - 경쟁사(TIKR, GuruFocus 등)는 지표만 보여주고 해석은 사용자 몫으로 남김
   - Tweezy는 "PEG<1"이 아니라 "회사가 버는 돈에 비해 싸게 거래되고 있어요"처럼
     먼저 번역해서 보여주는 것이 핵심 차별화
   - UI가 아니라 카피(문구) 자체가 제품이라는 인식으로 개발할 것

2. **이지모드 = 토스의 "쉬운 화면", 프로모드 = 숨겨진 디테일**
   - 토스는 "간편 송금" 뒤에 실제 은행 시스템의 복잡함을 다 숨김
   - Tweezy도 이지모드 뒤에 프로모드의 모든 정량 지표(대가 원칙, 세부 수치)가
     그대로 존재하되 처음 화면에는 노출하지 않는 구조를 유지

3. **네이밍도 이 철학의 연장**
   - "Tweezy"라는 이름 자체가 "핀셋으로 콕 집어낸다"는 전문적 행위를
     캐주얼하고 무겁지 않은 톤으로 재포장한 것
   - 브랜드 전 영역(이름, UI 카피, 필터명)에서 이 톤을 일관되게 유지할 것

### 모든 필터명/UI 카피에 적용할 판단 기준
**"이 문구를 투자 지식이 전혀 없는 친구에게 보여줬을 때, 3초 안에 이해되는가?"**
- 필터 하나를 만들 때마다, 화면 문구 하나를 쓸 때마다 이 질문을 통과해야 함
- 예시(통과): "사장님이 자기 돈으로 산 종목"
- 이 기준 미달 시 카피를 다시 쓸 것 (전문용어 그대로 노출 금지)

### 주의 — 쉬운 문구와 정확성의 균형
쉬운 문구로 단순화하는 과정에서 원래 지표의 의미가 왜곡되면 안 됨.
예: "사장님이 자기 돈으로 산 종목"이 실제로는 "스톡옵션 행사 후 세금 납부용
매도 뒤 소량 재매수"처럼 신호가 약한 케이스까지 뭉뚱그리면 사용자가 "속았다"고
느낄 수 있음. 따라서 모든 이지모드 자연어 카피에는 반드시 "더 알아보기" 연결
장치를 붙여서, 누르면 프로모드의 실제 공시 원문과 정확한 수치가 나오도록 설계할 것.
쉬운 문구는 진입점이지 최종 정보가 아니다 — 항상 정확한 근거로 드릴다운 가능해야 함.
